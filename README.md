# 🧛 VTM Territory Manager

## Sistema de Gestão de Territórios para Vampiro: A Máscara

Um sistema web para gerenciar domínios de clãs em suas crônicas de VTM.

### ✨ Funcionalidades

- 🗺️ Mapa interativo com territórios
- 🏴 Controle de clãs por região
- 🔒 Sistema de lock para edição colaborativa
- 📜 Histórico completo de alterações
- 👥 Multi-usuário com roles (Narrador/Jogador/Admin)

### 🚀 Como usar

```bash
# 1. Clone o repositório
git clone https://github.com/seu-usuario/vtm-territory-manager.git
cd vtm-territory-manager

# 2. Execute o inicializador
python run.py
